[B] Diagram
=============================================================
Diagram
  diagramId  = stable service identity
  revisionId = issued service revision
  id         = local scene.contents key
  revision   = nonnegative local revision number
  |
  +-- content --------------------> DiagramContent
  +-- sourceContext --------------> DiagramSourceContext
  +-- jumps? ---------------------> DiagramJump[]
DiagramContent
  revisionId = id:revision
  ascii + asciiSha256
  1..20000 printable ASCII characters; LF newlines
  structure
    +-- diagram
    +-- tree: parserVersion ascii-tree-1 | ascii-tree-2
          rootIds + nodes[id]
          label / line / branchColumn / column span
          parentId / childIds / foldRanges
          node id <- content revision + hash + line
DiagramSourceContext
  contentHash == SHA-256(content.ascii)
  binding?: sourceId / repositoryIdentity / corpus
    source-code <-> git-worktree
    document    <-> filesystem-documents
    corpus root must be absolute
  mappings[] --entityId-------> evidence[entityId]
             --range index---> sourceRanges[index]
             --range id?-----> matching range.id
  evidence: label + relative path + source line ranges
            originalLines preserve source text
Validation and queries
  validateDiagram -> canonical content / hash / joins / jumps
  diagramSource -> entries / forSelection / search
    results: mapping + entity + range + binding
Tree visibility
  visibleContentLines -> exclude collapsed foldRanges
  unknown content node -> STALE_CONTENT_NODE
  instance fold choices -> canvas.diagramViews
