LIFECYCLE / INVARIANTS
----------------------

Project
  `-- Representation (settled only in explorer)
      `-- current Revision (optimistically pinned by Draft.revisionId)
          `-- MappingDocument
              `-- LineGridScene
                  `-- recursive GridBox hierarchy
                      `-- GridContent (ASCII plus source mappings)

* A GridBox id is unique across the entire scene.
* A collapsed box must reference collapsed content.
* Expanded minimumSize reserves space; collapsed boxes shrink to their content.
* A draft is dirty when its name or serialized scene differs from its saved baseline.
* Save advances currentRevisionId; create can start blank or copy the active revision.
* Projection links map selected source evidence to pinned call-tree nodes.
* Compaction links map projected call-tree nodes to source-backed compacted rows.
