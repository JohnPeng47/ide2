Legend: 1 = exactly one, 0..1 = optional, * = many, --> = references

|       +-- selected call-tree nodes resolve file tree lines

\-- presentation/session models
    +-- DiagramCanvas
    |   +-- transform { offset { x, y }, scale }

    |   +-- commands : arrow pan | +/- zoom | 0 reset
    |   \-- focus target --> GridBox.id
    +-- DiagramExplorer
    |   +-- diagrams --> settled ProjectRepresentation records
    |   \-- active box tree --> LineGridScene.root
    \-- LocalChatThread [0..1 per selected region]
        +-- title
        +-- messages : LocalChatMessage [*]
        |   +-- id
        |   +-- role : user | assistant
        |   \-- text
        +-- verbosity
        +-- pending + progress
        \-- error + retry

KEY INVARIANTS
+-- Every GridBox.id is unique within a scene.
+-- Every position, minimum size, gap, and resolved edge is an integer.
+-- A collapsed box must reference collapsed content.
+-- An expanded box honors minimumSize; a collapsed box does not reserve it.
+-- A projection can target only its pinned project, representation, and revision.
+-- Unsaved name/scene changes or busy edits guard navigation and page unload.
\-- Only settled representations appear in the project diagram explorer.
