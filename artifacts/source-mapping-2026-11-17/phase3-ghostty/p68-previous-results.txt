• Yes, I think this is a stronger approach. Bottom-up aggregation
  gives a parent the evidence found throughout its branch. Giving the
  parent its own investigation catches responsibilities and
  connections that its children leave out.

  The main refinement is to define scope top-down, investigate bottom-
  up, and compute the unions automatically.

  1. Establish what each node represents. Before mapping, identify its
     responsibilities using the label, surrounding tree, and an
     initial source inspection. A leaf such as “glyph rendering
     system” may require investigating shaping, glyph lookup,
     rasterization, caching, atlas management, and frame preparation.
     Those can be internal investigation tasks without changing the
     displayed diagram. This matters because bottom-up traversal alone
     cannot help a broad leaf.

  2. Delegate coherent branches to subagents. Give each worker its
     branch, ancestor context, the whole diagram outline, and the
     pinned repository. Partition work by responsibility, allowing
     workers to follow code across folders. Small related leaves can
     share a worker. A broad leaf can justify several workers
     investigating its constituent responsibilities. Assign one owner
     to reconcile each node’s direct mappings.

  3. Collect direct evidence at the lowest nodes first. Each worker
     returns ranges, the claims those ranges support, and unresolved
     gaps. Save results incrementally so work survives partial
     completion. This directly addresses the runs that investigated
     many nodes and then submitted a tiny subset.

  4. Investigate each parent as children finish. The parent’s owner
     receives the child evidence and searches for the parent’s own
     orchestration, interfaces, resource ownership, and missing
     responsibilities. Its investigation remains obligatory even when
     the children already cover many files. “Independent” should mean
     a separate evidence obligation, while allowing the parent to
     reuse verified findings.

  5. Aggregate ranges deterministically. For each node, retain both
     its direct mappings and its accumulated branch coverage:

     direct(node) = evidence selected for this node's own claims

     branch(node) = union(
         direct(node),
         branch(child 1),
         branch(child 2),
         ...
     )

     Preserve which node contributed each range. Deduplicate overlaps
     within the same file and revision when calculating coverage. Keep
     separated intervals separate, so the union doesn’t sweep
     unrelated code between them into the mapping.

  6. Review missing connections before moving upward. The parent owner
     checks whether the collected evidence explains how the parts work
     together. Unresolved questions become targeted follow-up tasks.
     Completion requires inspecting the material claims and handoffs,
     with any remaining gaps recorded explicitly.

  For the resize example, the children would contribute the terminal
  and backend resize implementations. The parent investigation must
  still find the timer callback connecting request coalescing to
  Termio.resize(). Aggregating the children’s implementations cannot
  establish that connection by itself.

  The parent–child semantics need care. Our Ghostty tree mixes
  containment, ownership, calls, and data dependencies. A descendant’s
  lines belong in the branch’s accumulated coverage, but they do not
  automatically prove the parent’s claim. Keeping direct mappings and
  their provenance lets us answer both “where is this branch
  implemented?” and “what supports this particular statement?”

  Subagents would be most valuable for bounded discovery tasks and
  reviewing missing evidence. The coordinator should receive saved
  mapping references and short summaries, then merge the artifacts
  mechanically. Having it rewrite every worker’s ranges into one giant
  final JSON would recreate the submission failures we already
  observed.

  I’d evaluate this strategy on whether it recovers the missing
  shaping, reference-management, and handoff evidence, while tracking
  irrelevant ranges and unresolved claims. Parent coverage will grow
  automatically through aggregation. The harder—and more useful—test
  is whether the independent parent investigation discovers code that
  the descendants missed.
