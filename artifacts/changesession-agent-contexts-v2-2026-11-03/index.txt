Generation and integration
Each prompt-v2.txt is included verbatim in the saved context alongside captured baseline diagrams, exact target Git source and path-scoped before/delta evidence. Each generator updates complete assigned parents independently and proposes missing details without drawing them. Sibling diagrams remain read-only.

Contexts 01, 02, 03 and 04 share the original domain canvas and its g2 copies; 03 and 04 also share Projection. After evaluation, combine selected diagram-scoped changes against a fresh shared document baseline, reanchor connections, and accept a combined proposal. The current backend does not safely accept independently captured whole-canvas proposals sequentially merely because their diagram edits are disjoint.

No eval run, live diagram edit or ChangeSession acceptance was performed. The prior three immutable saved contexts are retained under Superseded - ChangeSession evals v1 (3 contexts).

Known carried-forward limitation
Whole-range DiffTree discovery exceeds the existing 8 MiB hunk-capture cap due unrelated investigation dumps. Inputs contain scoped code evidence, not fabricated API hunk IDs.
